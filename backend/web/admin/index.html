订阅配置

开启后，可在套餐管理页面复制 M3U/TXT 订阅地址，分享给用户导入第三方播放器（如 VLC、Tivimate 等）直接使用，无需开启开发调试模式。 订阅地址内的代理流链接采用专属验证参数，仅允许通过套餐订阅 Token 鉴权，不会影响普通设备 Token 的安全边界。

频道源配置

开启后，添加频道时可使用本地文件路径（如 /vol1/media/video.mp4）、file://、ftp://、webdav:// 等协议。 注意：请确保服务器有对应文件的访问权限。

EPG 节目源配置

支持配置多个源（每行一个），优先匹配前面的源。格式支持 .xml 或 .gz。服务端会自动拉取并仅加载所需频道到内存中。

台标缓存配置

配置台标包的根目录，按行分割，拉取时会自动拼接清洗后的频道名称。例如：http://example.com/logo/cctv1.png

客户端在线升级 (OTA) 配置

必须为整数。客户端版本号小于此值将提示升级。

FCC (Fast Channel Change) 毫秒级换台加速

开启后，客户端通过代理播放 UDP/RTP 组播流时，后端将尝试与运营商的 FCC 服务器进行握手并拉取历史流，实现秒开。
⚠️ 警告：要使 FCC 正常工作，Docker 必须使用 network_mode: host 或 macvlan，并且必须在主路由器中将下方的 UDP 端口范围映射到本服务器！
如果服务器在内网(NAT后)，需要填写路由器的公网IP或DDNS域名。
填写 auto 可自动检测公网IP（需要服务器能访问外网）。

系统维护模式

开启后，非测试设备在连接时将进入全屏维护提示，自动停止播放视频，以便您进行系统级维护。

开发与安全配置

强烈建议在生产环境中保持关闭！若开启，其他人只要知道 Token 即可脱离官方客户端，在浏览器或第三方播放器中播放。
