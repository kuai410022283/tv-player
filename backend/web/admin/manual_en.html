Quick Start

Login to Dashboard

Open http://YOUR_SERVER_IP:PORT/admin/ in your browser and enter the admin password to log in.

Default Password: admin123, which can be modified via the environment variable ADMIN_PASSWORD. It is highly recommended to change the password immediately after your first login.

UI Overview

The admin panel uses a sidebar navigation + right content area layout. The sidebar navigation is grouped by function modules. Click on any item to switch pages. The version number displayed at the top indicates the current server-side version.

  • Dashboard — System overview displaying channel, device, and stream statistics
  • Content Management — Core management of channels, groups, and M3U sources
  • Client Licensing — Device management, plan management, and access logs
  • System Settings — Global settings, system update, master-backup sync, and system logs

Dashboard

The Dashboard is the home page of the administration portal, showing critical system operational indicators to help administrators quickly understand system status.

Statistical Indicators

  • Total Channels / Online — The total size of the channel library and the number of currently playable channels
  • Active Streams — The number of proxy stream sessions currently being pulled by clients
  • Authorized Devices / Pending — The number of approved devices and devices waiting for approval
  • Online Devices — The number of devices with active connections in the last 5 minutes
  • M3U/TXT Sources — The number of configured external playlist sources
  • Total Play Time — Cumulative play time across all devices
  • Uptime / Memory Usage — Server running time and current memory usage

Recent Access Records

The "Recent Access" table at the bottom of the dashboard displays the latest operations from devices, including channels played, IP addresses, operation times, etc. Click the "Refresh" button to load the latest data.

Channel Management

Channel Management is the core functional module of the administration panel. It supports channel creation, modification, deletion, ordering, health checks, and batch operations.

Channel List

The channel list displays all channels in a table format, showing channel name, group, stream URL, source, stream format, direct/multiplex status, and enabled status. It supports search by name and filtering by source.

Add Channel

  1. Click the 「+ Add Channel」 button in the top right corner.
  2. Name — Fill in the channel name.
  3. Group — Select the group this channel belongs to.
  4. Stream URL — Enter the media stream URL (supports formats like HLS, TS, FLV, RTMP, RTSP, MP4, DASH, etc., and also supports local file paths).
  5. Stream Type — Manually specify the stream format (e.g., hls, ts, mp4), leave blank for auto-detection.
  6. Content Type — Choose "Live" or "VOD", leave blank for auto-detection.
  7. Enable Channel — Toggle control. When off, the channel will not appear in clients or subscription lists.
  8. Direct Mode — When enabled, the client connects directly to the original stream URL to play without proxying through the server.
  9. Multiplex Stream — When enabled, if multiple clients watch the same channel, the server only pulls one stream from the source, saving server bandwidth (requires Direct Mode to be turned off).
  10. Logo URL — Set the channel logo image address.
  11. EPG Channel ID — Set the channel identifier in the EPG program guide to match program data.
  12. User-Agent — Custom User-Agent for requests, overriding group and source settings.
  13. Custom Request Headers — Custom request headers in JSON format, e.g., {"Referer": "https://example.com"}.
  14. Custom FCC Server — Set the dedicated FCC (millisecond channel switching) server address for this channel.
  15. Custom FCC Protocol — Select the FCC protocol type (Telecom, ZTE, Huawei, etc.).
  16. Proxy Type — Configure SOCKS5 proxy, supporting: Inherit Group settings, Bypass Proxy, or Custom SOCKS5.
  17. Sort — Smaller numbers appear first.
  18. Click 「Save」.
Content Type Description: In Live mode, clients do not support pause or progress bar seeking; in VOD mode, clients support pause, seeking, audio track switching, and subtitle switching. If a wrong type is selected, client functionalities may malfunction. Leaving it blank for auto-detection is recommended when unsure.
Stream URL Description: Supports network URLs and local file paths (requires "Allow Local File Paths" to be enabled in Global Settings). Network URLs support http/https, rtmp, rtsp, udp, rtp, etc.

Edit Channel

Click on any row in the channel list to open the editing modal. The editing modal also provides the following feature:

  • Mirror Clone — Clone this channel to other sources and groups. The cloned channels will automatically sync their stream URLs with the primary channel. Useful when a channel exists in multiple sources and needs to be synchronized.

Channel Enable/Disable

Each channel has an "Enable" switch:

  • Enabled — Channel displays normally in client lists and subscription exports.
  • Disabled — Channel is hidden from clients and subscription exports, but remains visible in the admin panel for easy re-enabling.
Difference from Delete: Disabling is a soft toggle that can be reverted at any time. Deleting is permanent. It is recommended to disable instead of deleting if you might need the channel again.

Direct Mode

When enabled, clients connect directly to the source stream URL to play, bypassing server proxying.

  • Scenario: Clients can directly access the source URL (e.g., public streams).
  • Pros: Saves server bandwidth.
  • Cons: Cannot gather playback statistics, and proxy routing cannot be used.
  • Group Default Direct Mode: Group settings can define a default direct mode for all channels under that group.

Multiplex Stream (Multiplex)

When enabled, when multiple clients play the same channel, the server only pulls a single stream from the source and distributes it to all clients, saving a significant amount of bandwidth.

Note: Multiplexing requires Direct Mode to be disabled, and the stream format must be proxied (e.g., TS, HLS). Protocols like RTSP do not support multiplexing.

Proxy Configuration (HTTP / HTTPS / SOCKS5)

The system supports a 3-tier proxy configuration inheritance hierarchy: Channel → Group → Source, sorted by priority.

  • Inherit Group Settings — Uses the proxy configured on the group level.
  • Direct (Override Inherited) — Forces no proxy, bypassing upper-level configurations.
  • HTTP / HTTPS / SOCKS5 — Custom proxy address, format: http://user:pass@host:port or socks5://user:pass@host:port.

In the channel editor, you can customize the proxy settings to override group and source default options.

Channel Sorting

Hover and drag the 「Move」 column in the channel list to adjust the channel order. Once adjusted, click the orange 「Save Sort」 button in the top right corner to apply.

Health Check

Click the 「Health Check」 button and set the expected completion time. The system will detect if all channels are playable one by one. The detection uses a smooth rolling mechanism to avoid high concurrency requests to the source.

Suggestion: Health checks consume network bandwidth and source server resources. It is recommended to perform them during off-peak hours to avoid affecting user playbacks.

Batch Actions

Check multiple channels and click 「Batch Actions」 to perform the following operations:

  • Batch Enable — Enable all selected channels.
  • Batch Disable — Disable all selected channels (hidden from clients and exports).
  • Batch Delete — Delete all selected channels (permanent).
Warning: Deleting channels is irreversible. Please operate with caution. Disabling is recommended instead of deleting.

Search & Filter

  • Search Box — Fuzzy search by channel name.
  • Source Filter — Select specific sources (such as "Manual" or a specific "M3U Source Name") to filter lists.

Channel Source

The channel list displays the channel source, showing whether the channel was manually added or imported via M3U sync. The source property cannot be manually modified.

Group Management

Groups are used to classify and organize channels. Clients will also display channels grouped accordingly.

Add Group

  1. Click the 「+ Add Group」 button.
  2. Name — Enter the group name.
  3. Sort — Smaller numbers appear first.
  4. Group-wide Direct Mode — When enabled, all channels in this group default to Direct Mode.
  5. Group-wide Multiplexing — When enabled, all channels in this group default to Multiplexing (requires all channels in the group to support proxying).
  6. User-Agent — Default User-Agent for all channels under this group.
  7. Custom Request Headers — Default request headers for all channels under this group.
  8. Proxy Type — Default proxy configuration for all channels under this group.
  9. Click 「Save」.
Inheritance Notice: Parameters configured on the group level (such as User-Agent, custom request headers, and proxy settings) will be overridden by channel-level custom settings. If a channel has no custom settings, it will inherit these group defaults.

Group Sorting

Similar to channel sorting, drag the 「Move」 column to adjust order and click 「Save Sort」.

Batch Actions

Select groups and click 「Batch Actions」 to delete the groups along with all channels inside them (permanent).

Warning: Deleting a group will also delete all channels under that group. This action is irreversible.

M3U Source Management

Supports auto-pulling channel and group data from external M3U/TXT subscriptions, facilitating automated channel library management.

Add Source

  1. Click the 「+ Add Source」 button.
  2. Source Name — Name of this source for identification.
  3. URL — Remote M3U/TXT file URL.
  4. Auto Sync — When enabled, the system periodically updates data at the set interval.
  5. Sync Interval — Time interval in hours for auto-sync.
  6. User-Agent — User-Agent used when pulling the source URL, also serving as the default User-Agent for channels imported from this source.
  7. Custom Request Headers — Request headers added when pulling the source.
  8. Proxy Type — SOCKS5 proxy configuration for pulling the source.
  9. Click 「Save」.
Suggestion: The sync interval should not be too short (recommended: at least 6 hours). Frequent requests may lead to IP bans or rate limiting from the source site.

Paste & Import

Click the 「Paste & Import」 button to copy M3U text or upload local .m3u/.m3u8/.txt files:

  • Format as Standard M3U — Automatically format content to standard M3U (with #EXTINF tags).
  • Format as Minimal TXT — Automatically format content to simplified TXT format (one URL per line).
  • Import Source File — Upload a local .m3u/.m3u8/.txt file directly.

Manual Sync

Click the 「Sync」 button in the source list to manually trigger a sync immediately, without waiting for the next schedule.

Note: After adding a source, channels and groups are created automatically. Deleting the source will not delete the created channels and groups automatically; they must be cleaned up manually.

Device Management

Manage all connected client devices, supporting approval, licensing, banning, and details viewing.

Device Statuses

  • Pending — New device registered, requiring manual approval (unless Auto Approve is enabled).
  • Approved — Devices authorized to play streams.
  • Rejected — Devices rejected by the administrator.
  • Banned — Banned devices, blocked from accessing the server.
  • Expired — Authorized devices whose licensing validity has expired.

Approve Device

  1. Click the 「Approve」 button next to the device in the pending list.
  2. Choose a plan to bind (optional), or manually enter the validity days and maximum simultaneous streams.
  3. Confirm the approval.
Note: Binding a plan makes the device inherit the validity and concurrent stream limits from the plan. If the plan content is modified later, already approved devices will not update automatically; they must be re-bound.

Device Details

Click the 「Details」 button to view comprehensive device metadata:

  • Device Name — Model name of the device (e.g., Xiaomi MiBox).
  • Device ID — Unique hardware identifier.
  • IP Address — Current IP address used by the device.
  • IP Location — Geographical location parsed from the IP.
  • OS Version — OS version running on the device.
  • Client Version — App version number.
  • NIC Name — Network interface name used by the device.
  • Remarks — Custom notes added by the administrator.
  • Plan — Current plan name bound.
  • Expiry Time — Expiration time of the authorization.
  • Simultaneous Connections — Maximum concurrent connections allowed.
  • Traffic Used — Cumulative bandwidth traffic used by the device.
  • Last Active — Latest heartbeat or access time.

Tester Mark

Devices marked as 「Tester」 are not restricted by System Maintenance Mode, allowing administrators to debug and test settings during maintenance.

Batch Actions

Select multiple devices to batch approve, reject, ban, or delete.

Warning: Ban and delete operations take effect immediately. Banned devices' tokens are invalidated instantly, causing clients to disconnect. Batch operations cannot be undone.

Filter & Search

Filter devices by status, or search by device name, IP, or ID.

Plan Management

Plans are used to manage device authorizations in batches, defining validity days, concurrent connection limits, and channel group access permissions.

Create Plan

  1. Click the 「+ Add Plan」 button.
  2. Plan Name — Name of the plan.
  3. Validity (Days) — Number of valid days for device authorization.
  4. Simultaneous Connections — Maximum concurrent streams allowed per device.
  5. Price — Optional, for display purposes only.
  6. Description — Optional, description text of the plan.
  7. Allowed Channel Groups — Select the groups this plan can access (drag to sort). Leaving all unselected blocks all channel access.
  8. Once saved, the system automatically generates an M3U/TXT subscription token for the plan.

Subscription Links

Plans support generating M3U/TXT subscription URLs for direct import into third-party players (e.g., VLC, Tivimate).

Prerequisite: The "External Subscription" feature must be enabled in Global Settings. Subscription URLs use dedicated validation tokens to isolate device tokens and maintain security.
Note: Modifying plan details (validity, concurrent limits, associated groups) does not automatically update existing devices already bound to the plan. They must be re-bound to apply the new settings.

Global Settings

The Global Settings page contains multiple configuration modules grouped by functionality.

Server Auth & Network Configuration

  • Server Name — Custom server name displayed on the client UI (max 20 chars, leave blank to hide).
  • App Display Name — Desktop icon name of the client app, defaults to "MediaPlayer". Changes take effect on next client startup (Note: Only applies to Android TV launchers like Xiaomi, Dangbei, etc., not standard Android mobile/emulator launchers).
  • Custom External Server URL — External server URL for client connections, leave blank to auto-detect.
  • Backup Server URLs — Backup addresses client will try sequentially if the main address fails (one per line).
  • Authorization Key — Base64-encoded string required by clients to register with the server, copyable directly.

Subscription Settings

When the external subscription feature is enabled, you can copy M3U/TXT subscription links on the 「Plan Management」 page and share them with users for direct import into third-party players (e.g., VLC, Tivimate).

Channel Source Settings

When "Allow Local File Paths" is enabled, channel stream URLs can use protocols like file://, ftp://, webdav://, etc.

Device Authorization Settings

  • Auto Approve — Automatically approve new device registrations. You can choose to bind a default plan or configure default parameters.
  • Default Simultaneous Connections — Connection limit for auto-approved devices.
  • Default Validity (Days) — Validity days for auto-approved devices (0 = never expires).

Client Announcement Settings

Set a system announcement (marquee text). The announcement text will scroll across the top of the client screen. You can set the broadcast interval in seconds (0 means show only once at startup and when switching channels).

EPG Source Settings

  • EPG Source URLs — Supports multiple XMLTV format sources (one per line), supporting .xml and .gz formats.
  • Auto Refresh Interval — Interval in hours for periodically fetching EPG data.
  • Global Time Shift — Time offset to adjust EPG program times (positive value delays, negative value advances), used to correct timezone discrepancies.
  • Click 「Force Pull EPG」 to trigger an immediate EPG update.

Channel Logo Cache Settings

  • Logo Policy — Select logo lookup priority: Local First (look up in local directory first), Source First (prioritize external URL logos), API First (prioritize logos provided by API interfaces).
  • Logo Repository Directory — Path to the logo package directory. The system automatically matches channel names to pull corresponding logo files.
  • Supports caching existing external logos, incremental pulling (new channels only), and full overwrite pulling (pulling all logos again).

Boot Advertisement / Splash Settings

Configure advertisements shown to users when the client app launches:

  • Mode — Image mode or Video mode.
  • Media URL — Address of the image or video file.
  • Max Show Duration — Maximum duration in seconds before the ad closes automatically.
  • Skip Delay — Seconds before the user is allowed to press OK to skip the ad.
Warning: Do not fill in live stream URLs (like m3u8) here. It will cause severe app lag during startup.

OTA Online Upgrade Settings

Configure client online upgrade notifications:

  • Latest Version Code — Clients with a version code smaller than this value will be prompted to upgrade.
  • Display Version Name — E.g., v1.2.0.
  • APK Download URL — Direct download link of the new APK package.
  • Changelog — Description of fixes and new features in the new release.
  • Force Update — When enabled, the client app cannot be used without completing the upgrade.

FCC Millisecond Channel Switching

Fast Channel Change feature. When enabled, UDP multicast streams are utilized to achieve millisecond-level channel switching experiences.

  • FCC Server Port Range — Port range for UDP data transfers (start and end ports).
  • Default FCC Server — Default FCC server address.
  • FCC Vendor Protocol — Select FCC protocol type (Telecom, ZTE, Huawei, etc.).
Important: FCC requires the Docker container to run in network_mode: host or macvlan, and the UDP port range must be mapped/forwarded in your router settings.

System Maintenance Mode

When enabled, non-tester devices will see a full-screen maintenance notice and playback will stop. This allows administrators to perform server maintenance or upgrades. Devices marked as "Tester" are exempt from this restriction.

Tips: After modifying the admin password, current sessions will remain active until you log out. If the server address is modified, already distributed authorization keys will need to be re-copied.

Master-Backup Sync

Master-Backup Sync is used to establish multi-node architectures, enabling data hot backup and load balancing.

Master Server Settings

  1. Set the Sync Serve Token for data pulling authorization, which will be used by backup nodes.
  2. Once saved, backup nodes can use this Token to pull configurations from the master node.

Backup Node Settings

  1. Enable 「Run as Backup Edge Node」.
  2. Fill in the Master Node URL.
  3. Fill in the Master Sync Token (i.e., the Sync Serve Token configured on the master server).
  4. Set the Auto Sync Interval in minutes.
  5. Save the configuration.
Warning: 「Force Overwrite Pull Immediately」 is a dangerous operation. It will immediately overwrite all data on the current backup node (including channels, groups, devices, and plans) with the master node's data.

Client Usage Guide

The following instructions apply to the Android TV / Mobile client application.

Connect to Server

  1. Launch the client app for the first time to enter the server configuration interface.
  2. Enter the Authorization Key provided by the administrator (which can be copied as a Base64 string at the top of the 「Global Settings」 page in the admin panel).
  3. The client will automatically parse the server address and token to complete the connection.
  4. Once connected, the channel playlist will load automatically.
Tip: If the server address changes in the future, you only need to get a new authorization key and update it in the client settings, without reinstalling the app.

Channel Navigation & Switching

  • Channel List — Categorized by groups. Press Left/Right to switch groups, and Up/Down to navigate channels.
  • Number Pad Switching — Input channel numbers directly via the remote control number pad to switch.
  • EPG Guide — View current and upcoming program schedules in the channel list (requires EPG sources configuration).
  • Favorites — Add frequently watched channels to your favorites list for quick access.
  • Playback Catch-up — For channels supporting catch-up, select past programs from the EPG list to playback.

Live Mode Controls

  • OSD Panel — Press the OK key to show. Press OK again to play/pause (play/pause is only supported in VOD mode).
  • Volume Control — Use the remote control volume keys to adjust.
  • Info Display — The OSD panel displays the current channel name, program details, clock, etc.
  • OSD Auto Hide — The panel automatically hides after 10 seconds of inactivity.
Notice: Pause and progress bar seeking are not supported in Live mode. If you need these features, the channel content type must be configured as VOD (Video on Demand).

VOD Mode Controls

  • Play / Pause — Press OK to toggle (triggered by the second OK press when OSD is visible).
  • Progress Seeking — Press Left/Right direction keys to seek backward/forward on the progress bar.
  • Audio Tracks — Click the 「Audio Track」 button on the OSD panel to select from available audio tracks.
  • Subtitles — Click the 「Subtitles」 button on the OSD panel to select from available subtitle tracks.
  • Progress Bar — The OSD panel displays current playback progress and total video duration.
  • Loop Playback — Automatically restarts playback from the beginning when a video ends, preventing black screens.
Tip: Audio track and subtitle buttons only appear if the channel stream contains multiple audio tracks or at least one subtitle track. They will not show if there is only one audio track and no subtitles.

Remote Control Key Definitions

  • OK Key — First press shows OSD (without pausing). Second press when OSD is visible toggles play/pause.
  • Left / Right Keys — Switch focus when OSD buttons are focused; adjust progress bar when no buttons are focused (VOD mode).
  • Up / Down Keys — Navigate the channel list.
  • Back Key — Return to the channel list or exit the application.
  • Number Keys 0-9 — Fast switch channels by entering channel numbers.

Client Settings

The client settings panel provides the following adjustments:

Screen Ratio

Supports multiple aspect ratio modes: Fit, 16:9 Stretch, Crop, Force 4:3, Force 16:10, and Fill Screen. Adjust this setting if the screen aspect ratio seems distorted.

Decoder Mode

  • Auto — The system automatically chooses the best decoder.
  • Hardware Decoder — Force hardware decoding. Offers high performance but might not support all stream formats.
  • Software Decoder — Force software decoding. High compatibility but increases CPU usage and power consumption.
Suggestion: Try switching decoder modes if you experience playback lags or screen tearing. Hardware decoding is efficient, while software decoding is highly compatible.

Player Engine

  • Auto — Automatically select the best player engine based on the channel format.
  • ExoPlayer — Google's official player engine, offering stable performance.
  • MPV — MPV-based player engine, providing broader compatibility.

Channel Switch Mode

  • Fluid Mode — Faster switching. Does not reset the player engine, ideal for switching between channels of the same format.
  • Compatible Mode — More stable. Fully resets the player engine on each channel change, ideal for switching between vastly different stream formats.

Local Proxy

Used for local proxy forwarding of multicast streams (UDP/RTP/RTSP). When enabled, the client launches a local proxy service to forward multicast data to the player. Defaulted to disabled on some TV models (like Xiaomi TV) due to compatibility issues.

Picture-in-Picture (PiP)

When enabled, pressing the Home key during playback puts the video into a small picture-in-picture window, letting you navigate other screens while watching.

Other Settings

  • Adjust Brightness via Volume Keys — Use volume keys to adjust brightness in the playback UI.
  • Brightness Gesture — Swipe vertically on the left side of the screen to adjust brightness.
  • Volume Gesture — Swipe vertically on the right side of the screen to adjust volume.
  • Global Progress Bar — Off/Top/Bottom. Display a slim playback progress line at the edge of the screen.
  • NIC Selection — Manually select the network interface card on multi-NIC devices.
  • Auto Start — Automatically launch the app on device boot.
  • Reverse Switch Keys — Swap the functions of the Up and Down keys in the channel list.
  • Control Scheme — Modern layout (info-centric) or Traditional layout (channel-centric).

Common Client Issues

  • Lag / Buffering — Try switching decoder modes (Hardware/Software) or check network quality.
  • Cannot Connect to Server — Check if the authorization key is correct, server address is reachable, or the device is banned.
  • Audio Only, No Video — Try switching decoder modes, or check if the video codec format is supported by the device hardware.
  • No Audio Track / Subtitle Buttons — Indicates the current stream only has one audio track and no subtitles, which is normal.
  • Device Pending Approval — First connection requires administrator manual approval in the backend, or enable Auto Approve in settings.
  • Long Black Screen during switching — Try switching to "Fluid Mode" to speed up channel changes.
  • Multicast Streams Cannot Play — Try enabling the "Local Proxy" feature in client settings.

FAQ

Q: How to modify the admin password?

Click "Change Password" at the bottom of the sidebar, enter the current password and the new password. Alternatively, set the environment variable ADMIN_PASSWORD to re-initialize the password.

Q: How do clients connect to the server?

At the top of the "Global Settings" page, copy the Base64-encoded server authorization key and paste it in the client application.

Q: What should I do if a channel cannot play?

Try the following troubleshooting steps:

  1. Use the "Health Check" feature in Channel Management to verify if the stream is online.
  2. Verify if the channel stream URL is correct.
  3. Disable Direct Mode to proxy the stream through the server.
  4. Check if the source restricts requests (User-Agent, Referer, etc.) and configure custom headers for the channel.
  5. Check the system logs for error details.

Q: How to configure client auto-updates?

Set the latest version code and APK download URL in the OTA upgrade section of "Global Settings". The client app will check for updates on startup.

Q: What does "Pending Approval" mean for a device?

Find the device in "Device Management" and click "Approve". You can also enable "Auto Approve" in "Global Settings" to bypass manual approval.

Q: Why is the subscription link not working?

Please verify:

  1. If the "External Subscription" option is enabled in Global Settings.
  2. If the plan is associated with channel groups.
  3. If the server external URL is configured correctly and reachable from the internet.

Q: How to backup and restore data?

Use the master-backup sync feature for automatic hot backup. For manual backup, copy the database file from the server directory.

Q: What is the "Enable Channel" switch?

Each channel has an "Enable" switch. When turned off, the channel is hidden from client lists and subscription exports, but remains visible in the admin panel. This is useful for temporarily hiding channels without deleting them.

Q: How to configure HTTP / HTTPS / SOCKS5 proxy?

Proxy settings support 3 levels of inheritance (Channel → Group → Source) in their respective editing modals. Proxy URLs should be in the format: http://user:pass@host:port or socks5://user:pass@host:port. Setting "Direct" blocks upper inheritance.

Q: What does source "Manual" mean?

"Manual" means the channel was added by the administrator manually, rather than imported or synchronized via M3U sources. Channels synced from sources show the source name.

Q: How to change the app icon label on device launcher?

Change "App Display Name" in "Global Settings" (e.g., "My TV"). It takes effect on next client startup (Note: Only applies to Android TV launchers like Xiaomi, Dangbei, etc., not standard Android mobile/emulator launchers).

Q: What if channel switching is slow on the client?

Change the client's Channel Switch Mode to "Fluid Mode". It does not reset the player engine, speeding up switches. If different channel formats cause screen artifacts, switch back to "Compatible Mode".

Q: What is a "Tester" device and how to set it?

Tester devices can bypass System Maintenance Mode for debugging. Set the tester flag in Device Management details.
