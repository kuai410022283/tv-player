1. Getting Started

MediaPlayer is a smart media server designed for managing IPTV streaming resources. It consolidates massive raw live stream URLs (M3U) and EPG XML files into a highly responsive, customized subscription channel list for TV clients.

Tip: Always configure at least one channel group before importing live sources.

2. Dashboard

The dashboard provides real-time statistics regarding your IPTV server health:

  • Total Channels: Aggregate count of imported playback links.
  • Online Channels: Active channels currently validated by the system.
  • Active Streams: Number of client devices currently fetching live streams.
  • Authorized Devices: Total device profiles registered on this console.

3. Channels Management

Add, edit, or remove channels individually. Each channel can be assigned custom stream link lines, EPG mappings, logo images, and specific decoder modes (hardware/software/ExoPlayer/VLC).

4. Groupings

Groupings organize channels into categories (e.g., Sports, Movies, News). Group names will display directly as channel list categories on the TV client UI.

5. M3U Source Management

Import bulk playlist sources via M3U files or remote HTTP links. The system automatically parses these files and allows you to bind channel sources to specific groups in bulk.

6. Active Streams

Lists all live streaming sessions currently active on the server. You can monitor device IPs, cache durations, and choose to forcibly terminate unauthorized streams.

7. Devices Authorization

Devices must be registered and approved before accessing subscriptions. You can grant access by copying base64 config lines, binding devices to specific subscription plans, or setting absolute expiration dates.

8. Subscription Plans

Manage subscription packages. A plan determines which channel groups are accessible to the associated devices, pricing info, and stream limits.

9. Access Logs

Tracks system events, backend terminal outputs, and client device connection status records. Great for troubleshooting buffering or authentication errors.
